## 6.1 Constraints and Limitations

| Constraint | Description |
|:---|:---|
| **Browser** | Chrome latest version recommended; Firefox is not supported |
| **User Permissions** | The operating user is `developer`. Direct `root` login is not supported. You can switch to `root` via the `sudo` command |
| **NPU Resources** | You can apply for one NPU resource and one CPU resource. Direct switching of resource types is not supported |
| **Image Upgrade** | Direct image upgrade is not currently supported. You need to shut down and delete the instance, and then recreate it |
| **Driver Upgrade** | Personal instance driver version upgrades are not currently supported; upgrades are managed uniformly by the platform |

> **Note:** The above constraints may change with platform version updates. Please follow CANN community news for the latest information.
