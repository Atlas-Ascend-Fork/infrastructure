# HiCANN 数字化协作平台介绍

## 网站链接

[HiCANN数字化协作平台](https://digital.hicann.cn/)

## 登录方式

平台使用 GitCode 账号统一登录：点击页面右上角「登录」，跳转 GitCode 完成 OAuth 授权即可。若暂无 GitCode 账号，可按 GitCode 页面指引注册后登录。

公开数据登录即览；管理类与审批类功能需要具备对应岗位角色（见「权限与角色」章节），角色可联系平台管理员开通。

## 平台定位

HiCANN数字化协作平台（HiCANN）是 CANN 开源社区的一站式数字化基础设施，将社区协作从群聊、邮件沉淀到线上，覆盖「需求 — 开发 — 构建 — 测试 — 发布 — 运营 — 治理」全流程：

- **对开发者**：降低参与 CANN 开源共建门槛，在线完成 Issue 分析、PR 门禁查询、检视权限申请、仓库与成员权限申请等操作；
- **对 SIG 与社区组织**：提供组织全景、贡献度量、会议度量、运营简报等支撑，让社区运转可度量、可复盘；
- **对治理团队**：以标准化电子流统一管理三方件引入、漏洞公告、仓库新建、镜像制作等合规与安全事务，流程留痕、审操分离。

平台持续迭代中，功能会不断上线完善。

## 社区开发

围绕代码研发全流程组织功能：

### 需求设计

- **Issue 分析**：全社区 Issue 数据分析视图，提供闭环率、闭环时长、响应达标率等 SLA 指标，支持按仓库、时间维度下钻，辅助需求与问题管理。

### 开发

- **构建触发**：全量 PR 数据与门禁记录查看，PR 流水线门禁自动触发、门禁评审流程管理与评审意见汇总，从流程上保障合入代码的质量。
- **检视查询**：按 SIG / 仓库 / 分支 / 文件路径查询对应检视人与审核人，清晰界定评审权限边界。

### 构建

- **研发度量**：构建维度的研发数据统计与趋势分析。
- **门禁效率**：各流水线门禁效率数据（时长、成功率等）的查看与导出。
- **版本构建**：版本包构建记录查看、版本包下载与流水线配置。
- **二级冒烟**：二级冒烟流水线的数据查看、触发与日志下载。
- **开发者测试**：开发者测试数据查看。

### 测试

- **集成验证**：整网集成验证任务与数据管理。

### 版本发布

- **发布计划 / 发布收集 / 发布评审 / 发布设置**：版本发布全流程管理——制定发布计划、收集发布内容、组织发布评审（支持评审详情回看）、维护发布配置（如 PyPI 仓）。

### 仓库管理

- **所有仓库**：CANN 社区代码仓统一列表与信息查看。
- **申请与审批**：新建仓库、仓库开源申请走多阶段电子流（材料预审 → 议题申报与 TSC 评审 → 新建仓库申请 → 基础设施审批 → CI 与 SIG 配置等），全程线上可追溯。

### 成员管理

- **成员总览**：各仓库成员构成查看。
- **申请与审批**：开发者在线申请仓库角色权限（检视 / 审核），电子流审批后生效。

### 镜像管理

- **镜像库**：社区镜像统一查看与上下架管理。
- **申请与审批**：镜像制作、镜像变更电子流。

## 社区治理

### 合规

- **三方件管理**：社区开源三方件清单与使用情况统计；三方件新增、变更走线上评审电子流，实现开源组件引入的规范化、流程化管控。
- **SBOM 管理**：软件物料清单（SBOM）数据查看与软件包下载。

### 安全

- **漏洞管理**：社区漏洞统一查看（所属仓库、修复状态等）；漏洞公告列表展示，公告发布走申请电子流，审批通过后面向社区公示。

## 社区运营

### 社区大屏

- **社区开源指数**：社区活跃度、贡献规模、开发者结构等核心指标的大屏可视化。

### 社区贡献

- **开发者贡献**：开发者维度的贡献统计（D2 / D1 分层、贡献明细、导出）。
- **开发者运营**：面向运营人员的开发者工作台，提供运营视角的度量与管理。
- **社区贡献（总览 / 社区健康度 / 详情）**：社区整体贡献趋势、健康度诊断与贡献明细下钻。

### 社区中心

- **组织全景**：SIG 架构与机制说明、所有 SIG 组信息一览。
- **组织运营**：SIG 维度的运营度量（人员构成、D2 / D1 分布、活跃趋势、开发者明细）。
- **会议度量**：SIG 会议数据度量。

### 仓库度量

- **仓库度量**：仓库维度的整体度量总览。
- **Issue SLA / PR SLA**：Issue 与 PR 的响应、闭环 SLA 达标情况管理。
- **代码统计**：各仓库代码量统计。

## AI 开发者工具

- **CANN 助手**：基于 CANN 领域知识库的 AI 问答助手，全站悬浮入口，支持多轮对话与历史会话。

## 全局功能

- **帮助中心**：各模块用户手册、指标解释，随功能迭代持续更新。
- **运营简报**：AI 日报、社区行动周报、月报（社区活跃、贡献、留存、贡献者分层等），支持订阅。
- **意见反馈**：平台使用问题的在线反馈与处理跟踪。
- **通知中心 / 个人中心 / 隐私声明**：站内通知、个人数据管理与隐私政策。

## 协作机制

### 统一电子流

平台各类申请（仓库、成员、三方件、漏洞公告、镜像等）均采用统一的电子流范式：

- 「我提交的申请 / 我审批的申请」双视角列表；
- 状态筛选（审核中 / 已通过 / 已驳回 / 未提交）与单号模糊搜索；
- 审批链可视化、审批意见必填、操作历史全程留痕；
- 支持撤回、驳回后重新提交。

仓库新建、仓库开源等复杂事务采用**多阶段电子流**：按阶段推进（材料预审、议题申报与 TSC / PMC / QA 评审、基础设施审批、配置生效等），每阶段内含明确的处理步骤与责任人。

### 权限与角色

平台采用基于角色的权限体系：公开业务数据登录即可查看；管理类与审批类功能按岗位角色授权，审批与操作职责分离，私有数据需具备对应授权方可访问。如需开通相关权限，请联系平台管理员（见下方支撑矩阵）。
