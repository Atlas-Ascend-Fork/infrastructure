# 新建仓申请指引

---
## 1. 入口

- **发起申请**：社区开发 → 仓库管理 → 全部仓库 → 「新建仓申请」按钮，进入申请页
- **查看进度**：仓库管理 → 申请与审批（[申请与审批](https://digital.hicann.cn/#/repo_manage/application_approval)）：
  - **我申请的**：自己提交的申请单；
  - **我审批的**：需要自己（作为审批角色）处理的申请单；
  - **与我相关的**：自己提交的 + 自己作为审批人参与的。
- 支持按电子流单号搜索、按状态/类型筛选，勾选「待我处理」可只看当前轮到自己操作的。
## 2. 功能简介

用户可以在平台上申请新建仓库，审批通过后系统自动完成建仓和仓库初始化配置。整个申请一共 8 个阶段：
| 阶段 | 名称 | 处理人                         |
|---|---|-----------------------------|
| 1 | 评审准备 | 申请人                         |
| 2 | 材料预审 | 基础设施团队、PMC 成员、社区架构师 |
| 3 | 议题申报&TSC评审 | 申请人                         |
| 4 | 新建仓库申请 | 申请人                         |
| 5 | 基础设施团队审批 | 基础设施团队                      |
| 6 | CI与SIG配置 | 申请人                         |
| 7 | CI与SIG配置生效 | 申请人                |
| 8 | 绑定账号| 申请人                     |



## 3. 申请操作流程

### 第 1 步：评审准备（提交申请）

填写申请表单并提交，**提交即正式创建申请单**，进入材料预审。
| 填写项 | 说明                              |
|---|---------------------------------|
| 是否同时新建SIG | 勾选后需上传 SIG 申报材料                 |
| 仓库名称 | -                               |
| 用途 | 自研软件（CANN） / 自研软件（非CANN） / 生态项目 |
| 责任人 | 责任人GitCode 账号                   |
| SIG组 | -                               |
| 仓库申报材料 | 上传 .ppt/.pptx 申报模板（[模板下载链接](https://gitcode.com/cann/community/blob/master/templates/%E6%96%B0%E5%BB%BA%E4%BB%93%E7%94%B3%E6%8A%A5%E6%A8%A1%E6%9D%BF%20v0.2.pptx)）  |
| SIG申报材料 | 勾选新建 SIG 时必填（[模板下载链接](https://gitcode.com/cann/community/blob/master/templates/SIG%E7%BB%84%E7%94%B3%E6%8A%A5%E6%A8%A1%E6%9D%BF%20v0.2.pptx)）                |

> 备注：新建后支持更新材料。
### 第 2 步：材料预审（等待审批）

本阶段为预审阶段，三个社区角色：**基础设施团队、PMC 成员、社区架构师**全部同意后才能进入下一阶段。任一角色成员均可审批。
- **三方全部同意** → 进入第 3 步；
- **任一方驳回**申请停留在本阶段，申请人可根据意见按需重新提交材料，驳回后可反复审批直至通过。


### 第 3 步：议题申报&TSC评审

在TSC会议评审后，于该阶段填写评审时间并上传评审结论截图。
### 第 4 步：新建仓库申请

将建仓信息按新建仓模板提交 [GitCode Issue](https://gitcode.com/cann/infrastructure/issues) 后，将 **Issue 链接**粘贴至页面解析。解析内容与一阶段填写信息对比，确认无误后点击下一步，最终建仓信息以该阶段展示信息为准。
### 第 5 步：基础设施团队审批

基础设施团队审核 Issue中建仓信息，同意后于该阶段**新建仓**成功。
### 第 6 步：CI与SIG配置

于该阶段录入 CI 配置和 SIG 配置（对应 Issue 与 PR），系统将自动跟踪状态。
### 第 7 步：CI与SIG配置生效

进入该阶段自动检查CI与SIG配置状态：

- Issue & PR 关闭或合入后，视为该仓库申请必要流程结束
### 第 8 步：绑定账号（仅同时新建 SIG 时展示）
未勾选新建 SIG，可跳过该阶段。
- 登录会议平台关联账号；
- 订阅邮件列表。
## 4. 撤回申请

在「我申请的」列表中，进行中的申请可点「撤回」。撤回后申请单关闭，流程终止。如仍需建仓，须重新发起申请。
